# Sharing a verse list via link

VerseList encodes the current list in the URL **hash fragment** (everything
after `#`), never a query string. Hash fragments are never sent to the
server, so there's no server-side or path-length limit to worry about —
even a very long list stays well within what any browser handles.

## Format

```
https://verselist.gospelgo.org/#refs=<url-encoded references>&order=bible
```

- `refs` — required. The list of references, in display order, joined with
  `;` and passed through `encodeURIComponent`. Each reference is plain text
  in the same format users type into the paste box (`Matthew 5:11-12`,
  `Acts 16:25`, `John 3:16`, `Romans 8`, ...) — no special escaping beyond
  the URL encoding.
- `order` — optional. Add `&order=bible` to open the link already switched
  to "Bible Order" view. Omit it (or use any other value) for "As Entered"
  order, i.e. the exact order the references appear in `refs`.

## Example

```
https://verselist.gospelgo.org/#refs=Matthew%205%3A11-12%3BLuke%206%3A22-23%3BActs%205%3A41%3BActs%2016%3A25
```

Decodes to: `Matthew 5:11-12;Luke 6:22-23;Acts 5:41;Acts 16:25`

## Building a link from another app

Any app (e.g. a future "Copy Verse List" button in Bible Peruser) can hand
off to VerseList by building this URL directly — no API call needed:

```js
const refs = ["Matthew 5:11-12", "Luke 6:22-23", "Acts 5:41", "Acts 16:25"];
const url = `https://verselist.gospelgo.org/#refs=${encodeURIComponent(refs.join(";"))}`;
```

VerseList also understands references without gospelgo-specific tooling —
full book names, common abbreviations ("matt", "1 cor", "ps"), and
chapter-only references ("Romans 8") all resolve on their own, so this
format works for anyone typing a list by hand too, not just for links
generated by a sibling app.
