# Sharing a verse list via link

VerseList encodes the current list in the URL **hash fragment** (everything
after `#`), never a query string. Hash fragments are never sent to the
server, so there's no server-side or path-length limit to worry about —
even a very long list stays well within what any browser handles.

## Format

The hash fragment is standard `key=value&key=value` query-string syntax —
build and read it with `URLSearchParams`, not manual `encodeURIComponent`
(that's what VerseList's own code does, so staying consistent means links
round-trip exactly).

```
https://verselist.gospelgo.org/#refs=<references>&order=bible&title=<name>
```

- `refs` — required. The list of references, in display order, joined with
  `;`. Each reference is plain text in the same format users type into the
  paste box (`Matthew 5:11-12`, `Acts 16:25`, `John 3:16`, `Romans 8`, ...).
- `order` — optional. Add `&order=bible` to open the link already switched
  to "Bible Order" view. Omit it (or use any other value) for "As Entered"
  order, i.e. the exact order the references appear in `refs`.
- `title` — optional. A name shown above the list and used as the browser
  tab title. **This is the only way a list gets a title** — VerseList's own
  paste box has no title field by design, so a title always arrives via a
  link like this one (see below).

## Example

```
https://verselist.gospelgo.org/#refs=Matthew+5%3A11-12%3BLuke+6%3A22-23%3BActs+5%3A41%3BActs+16%3A25
```

Decodes to: `Matthew 5:11-12;Luke 6:22-23;Acts 5:41;Acts 16:25`

## Building a link from another app

Any app (e.g. a future "Copy Verse List" button in Bible Peruser) can hand
off to VerseList by building this URL directly — no API call needed:

```js
const refs = ["Matthew 5:11-12", "Luke 6:22-23", "Acts 5:41", "Acts 16:25"];
const params = new URLSearchParams();
params.set("refs", refs.join(";"));
params.set("title", "Persecution & Rejoicing"); // optional
const url = `https://verselist.gospelgo.org/#${params.toString()}`;
```

VerseList also understands references without gospelgo-specific tooling —
full book names, common abbreviations ("matt", "1 cor", "ps"), and
chapter-only references ("Romans 8") all resolve on their own, so this
format works for anyone typing a list by hand too, not just for links
generated by a sibling app. A title passed this way still runs through
VerseList's basic profanity filter — it's not a security control, just a
decency check, but it applies to every title regardless of source.
